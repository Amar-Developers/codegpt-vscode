# Give the agent a task

Describe what you want in plain words, for example:

- *Fix the failing test in the cart*
- *Add a dark mode toggle to the settings page*
- *Explain how login works in this project*

The agent reads your files, shows every change as a diff you **Accept** or **Reject**, and runs commands (like your tests) only after you press **Run**. Secret files such as `.env` are never read or sent.
