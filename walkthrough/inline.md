# Edit code where you are

Select some code and press **Ctrl + Alt + K** (on Mac **Cmd + Alt + K**). Say what to change. The edit appears as a diff right in the file.

Other shortcuts:

- **Ctrl + Alt + G**: open the Code GPT panel
- **Ctrl + Alt + E**: explain the selected code
- **Ctrl + Alt + Y** / **Ctrl + Alt + U**: accept or reject a change
